# 强网杯提交包验证说明

报名材料不要直接从工作区根目录上传。请在仓库外建立一个只包含最终材料的目录，例如：

```text
D:\context\submission\2026-强网杯\
  01_报名表.pdf
  02_申报书.pdf       # 或 02_申报书.docx，按官方入口要求选择一个
  03_展示PPT.pptx
  04_展示视频.mp4
  05_源码仓库说明.txt
```

在 `context-keeper-main` 目录执行：

```powershell
python experiments/scripts/validate_submission_package.py `
  D:\context\submission\2026-强网杯 `
  --json-out D:\context\submission\2026-强网杯\manifest.json
```

验证器会检查报名表不超过 1 MB、申报书和 PPT 不超过 20 MB、视频为 MP4 且不超过 90 秒/20 MB，并使用 `ffprobe` 检查 H.264、AAC 和至少 800x600。它还会扫描 `.env`、密钥、JWT、GitHub PAT、真实凭据和疑似私密文件名。

缺少 `ffprobe` 时检查会失败，而不是把视频编码当作已验证。安装 FFmpeg 后重新执行；也可以用 `--ffprobe` 指定可执行文件路径。

报名表、最终视频和个人报名信息不能由仓库自动生成。验证器只检查你放入提交目录的实际文件，不会创建、转换、上传或覆盖材料。`manifest.json` 是检查记录，不包含护理原文。

通过后再进行人工复核：打开 PPT 检查字体和动画，播放视频确认画面来自本次 live/fixture 运行，并确认申报书中的每个指标都有对应 JSON、CSV、HTML 或 trace 证据。
