# Competition Materials

This folder groups the project files that are directly useful for an information security competition submission and defense.

## Recommended Reading Order

1. `项目策划书.md`
2. `核心创新点总结.md`
3. `对比实验报告.md`
4. `路演演示脚本.md`
5. `项目完善清单.md`

## File Guide

- `项目策划书.md`: overall project narrative and value proposition
- `核心创新点总结.md`: security and algorithm innovation points
- `对比实验报告.md`: quantitative comparison and experiment results
- `路演演示脚本.md`: demo and defense speaking script
- `项目完善清单.md`: remaining optimization and execution checklist
- `策划书-核心技术清单.md`: detailed technical breakdown

## Related Runtime Config

- Minimal competition runtime template: `config/.env.competition.example`
- Key setup guide: `config/KEYS_SETUP.md`
