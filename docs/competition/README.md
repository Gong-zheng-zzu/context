# Competition Materials

This folder groups the project files that are directly useful for an information security competition submission and defense.

## Recommended Reading Order

1. `比赛主链创新增强改造报告.md` - 历史基线、可信边界、实施阶段和验收证据
2. `比赛架构与可信演示手册.md` - 现场运行、能力边界和证据口径
3. `比赛定位与可信边界.md` - 项目定位和不应越过的陈述边界
4. `对比实验报告.md` - 仅登记通过证据门禁的定量结果
5. `核心创新点总结.md` - 安全机制与答辩素材
6. `项目策划书.md`
7. `路演演示脚本.md`（历史素材，使用前须与本手册的边界核对）
8. `项目完善清单.md`

## File Guide

- `项目策划书.md`: overall project narrative and value proposition
- `比赛主链创新增强改造报告.md`: audited historical baselines, trust boundaries, and phased acceptance evidence
- `比赛架构与可信演示手册.md`: verified architecture, live/fixture distinction, and release gates
- `比赛定位与可信边界.md`: competition positioning and claim boundaries
- `核心创新点总结.md`: security and algorithm innovation points
- `对比实验报告.md`: quantitative comparison and experiment results
- `路演演示脚本.md`: demo and defense speaking script
- `项目完善清单.md`: remaining optimization and execution checklist
- `策划书-核心技术清单.md`: detailed technical breakdown
