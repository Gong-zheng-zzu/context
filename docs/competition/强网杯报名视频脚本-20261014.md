# 强网杯报名视频脚本

版本：2026-10-14

## 录制原则

视频只展示 `context-keeper-main` 当前版本的真实 HTTP 响应。录制前固定 Docker 镜像、配置、演示账号和合成数据，先运行 health check、fixture smoke、live smoke。任何模型、数据库或外部服务失败，都保留错误和降级状态，不切换成静态成功画面。

视频推荐时长 4-6 分钟，同时保留 90 秒剪辑版。屏幕不得出现 `.env`、JWT、密码、PAT、数据库凭据、真实护理原文或本机路径。

## 现场主线

```text
护理记录 -> ASDF/CASIA/PCCM-S -> O-M-P-R 因果证据
          -> 人工复核 -> 三存储写入 -> RRF 来源审计
          -> 隔离用户/会话跨存储删除验证
```

## 4-6 分钟版本

### 0:00-0:25 项目定位

画面：打开 `web/competition_console.html?mode=live`，确认页面显示实时模式、服务状态和本次 `trace_id`。

旁白：

> 忆安智护面向智慧养老护理数据治理。它把合成护理记录转成可审计的安全决策、因果证据、检索来源和跨存储删除验证。系统辅助护工和医生整理信息，不替代诊断或护理判断。

### 0:25-1:05 输入与安全判定

画面：输入一条不含真实个人信息的合成护理记录，提交分析请求。

必须展示：输入哈希、`trace_id`、ASDF 归一化步骤、span 映射、CASIA 命中上下文、PCCM-S 决策、早停或降级原因。

旁白：

> ASDF 先处理空格、符号和变形表达，并保留可回溯的 span 映射。CASIA 使用上下文窗口抑制普通护理记录的误报，PCCM-S 汇总规则和上下文证据。这里的结果来自服务端响应，不从浏览器日志推断。

### 1:05-2:00 O-M-P-R 因果证据

画面：打开因果结果，逐字段展示 Object、Mediator、Property、Result 的原文 span。

必须展示：候选关系、字段分数、否定和时序校验、模型层级、延迟分解、`verified`/`needs_review`/`abstain` 状态。

旁白：

> 因果模块先生成规则候选，再由本地模型限时裁决冲突。每个字段必须能在原文中定位，顺序、否定和时序通过校验后才标记 verified。证据不足时系统主动 needs_review 或 abstain，不凭医学常识补写机制。

### 2:00-2:35 人工复核

画面：以医生或比赛评测角色打开待复核队列，修改一个字段，提交复核。

必须展示：原预测、修正值、证据 span、队列状态、数据/规则/模型版本和 trace。

旁白：

> 人工修改会进入隔离的复核记录，不直接覆盖原始预测，也不自动进入训练集。这样可以保留错误样本和修正依据，供后续开发集校准。

### 2:35-3:25 三存储与 RRF 来源审计

画面：展示写入状态，再执行检索。

必须展示：唯一 `doc_id`、Qdrant/Neo4j/TimescaleDB 状态、每路排名、命中来源、RRF 分数、单路延迟、总墙钟延迟和 fusion mode。

旁白：

> 检索结果只读取服务端的 retrieval metadata。三路全部就绪才显示 `rrf_3_sources`；任一路为空、超时或失败，就明确显示二路或向量回退，并把这次请求从正式三路统计中分开。

### 3:25-4:20 跨存储删除验证

画面：使用专用评测用户执行 dry-run，确认后执行删除，再执行相同检索探针和第二次幂等删除。

必须展示：删除前后计数、目标探针、控制作用域保留情况、`verification_id`、`scope_hash`、`evidence_sha256`、幂等结果。

旁白：

> 这里称为隔离用户或会话跨存储删除验证。系统检查目标作用域在各存储的计数和检索探针，同时确认控制用户仍可检索。它不宣称参数级机器遗忘或物理不可恢复。

### 4:20-5:00 证据边界

画面：打开证据摘要，展示数据集状态、配置指纹、运行时间和结果等级。

旁白：

> 我们把结果分为已验证、受控初步和历史问题基线。当前安全消融和主链 smoke 已有受控运行记录；因果冻结集、人工复核 RRF 和真实三存储删除证明，必须在对应门禁通过后才写入正式成绩。多模态、记忆子图、冷热分层和研究 Agent 只作为受控扩展。

## 90 秒版本

1. 0:00-0:12：项目定位和 live 状态。
2. 0:12-0:30：安全判定卡片，展示 ASDF/CASIA/PCCM-S 和 trace。
3. 0:30-0:48：O-M-P-R span、校验状态和人工复核。
4. 0:48-1:08：三存储写入、RRF 来源排名和真实降级状态。
5. 1:08-1:22：删除前后探针、证明哈希和控制作用域保留。
6. 1:22-1:30：证据等级和限制说明。
