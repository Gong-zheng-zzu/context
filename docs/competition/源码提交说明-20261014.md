# 源码提交说明

源码目录为 `context-keeper-main`，比赛演示入口为 `web/competition_console.html`，服务端入口为受保护 HTTP 运行时。

提交前在仓库目录执行：

```powershell
go mod verify
docker compose config --quiet
python -m unittest discover -s experiments/scripts -p "test_*.py"
python experiments/scripts/smoke_test.py --mode fixture
python experiments/scripts/release_guard.py
```

报名包不包含 `.env`、JWT、PAT、数据库凭据、模型权重、真实护理数据或本机运行目录。正式成绩必须绑定数据集哈希、配置指纹、容器版本和 trace 证据；未通过门禁的内容标为受控初步结果或历史问题基线。
