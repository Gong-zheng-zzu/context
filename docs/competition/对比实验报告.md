# 对比实验报告（证据门禁版）

> 本文件是正式评测报告模板。仓库中的历史演示数字已移除，避免把未经过同配置复现实验的数据用于答辩。

## 实验目标

在同一数据集、同一清理流程和固定配置下，对比完整系统、向量基线和过滤基线，并保留每条结果的来源审计对象。因果抽取另行记录 O-M-P-R、规则命中、PCCM 分量和模型/降级状态。

## 运行门禁

报告只有在以下检查全部通过后才能生成：

- 数据集内容哈希、查询顺序和配置指纹已记录；
- 三个运行从干净作用域开始，种子数据数量可核验；
- 每条检索结果包含 `doc_id`、来源、来源排名、RRF 分数、单路延迟和总延迟；
- 来源失败、超时或为空时明确标记二路或向量回退；
- 运行目录不包含令牌、密码、`.env` 或私有实验数据。

## 现场说明
