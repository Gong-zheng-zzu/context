# 忆安智护未完成能力与准确率补齐执行报告

> 本报告是比赛主链的实施台账。它只记录有数据集、配置、运行产物和代码证据支持的结果。历史结果与受控原型不得替代正式冻结评测。

## 一、当前可信边界

比赛主链固定为：

`护理记录 → ASDF/CASIA/PCCM-S → O-M-P-R 因果证据 → 人工复核 → 三存储/RRF → 跨存储删除验证`

当前必须如实说明：

| 能力 | 当前状态 | 可引用证据 |
| --- | --- | --- |
| ASDF/CASIA/PCCM-S | 已接入主链，但正式安全门禁未通过 | 纯正样本检出率 94.22%，缺少 benign 分母，不能称准确率 |
| O-M-P-R | 已有证据约束和规则回退，准确率与延迟未达门槛 | 历史 Tuple F1 0.5128，平均延迟约 10.6 秒 |
| 三路 RRF | 有来源审计和降级契约，正式 300/500 查询尚未完成 | 30 查询仅作受控初步结果 |
| 删除验证 | 有跨存储删除流程，删除后探针仍需修复 | 目标文档 ID 曾在删除后被检索返回 |
| 三维记忆/冷热分层/多模态/研究 Agent | 受控扩展或进程内原型 | 不进入正式主链成绩 |

## 二、实施顺序

1. 固化攻击、正常护理、上下文歧义和因果冻结数据的 manifest、哈希与复核状态。
2. 完成 ASDF 归一化 span 映射、CASIA 配置审计和 PCCM-S 开发集校准，并输出消融结果。
3. 完成 O-M-P-R 多候选、span、否定、时序、缓存和本地 3B 限时回退。
4. 完成三存储种子、同配置向量/过滤/RRF 对照及来源故障降级统计。
5. 修复删除后检索残留、禁用存储误报成功、审计证明哈希不稳定和会话自动重建问题。
6. 将黑匣子、三维记忆、冷热分层和隐私保护页面改为 live 读取真实 API，fixture 才显示样例。
7. 冻结评测集，运行 Docker Linux 门禁，只有通过证据门禁后才更新策划书正式成绩。

## 三、统一验收门槛

- 安全：总防御率 ≥95%，每类攻击 ≥90%，正常误伤率 ≤3%，PII span F1 ≥0.92。
- 因果：严格 Tuple F1 ≥0.75，字段宏平均 F1 ≥0.88，无因果误报率 ≤5%，否定和时序准确率 ≥95%，线上 p95 ≤3 秒。
- RRF：相对向量基线 MRR 提升 ≥5%，Recall@5 不下降；故障请求与三路成功请求分开统计。
- 删除：目标作用域四类存储为空，删除后检索探针为空，控制作用域保留，第二次删除幂等，证明哈希可重算。

## 四、证据门禁

正式报告必须同时记录数据集 SHA-256、规则/Prompt/模型版本、配置指纹、容器镜像、随机种子、运行时间、清理流程、失败样本和 trace 证据。缺少任一项时，结果降级为“受控初步结果”。

合成数据只有在两名标注者独立复核、冲突经第三人仲裁并生成不可变 manifest 后，才能标记为冻结测试集。任何 `synthetic_unreviewed` 或 `auto_derived_unreviewed` 结果不得写入正式成绩。

## 五、禁止表述

在删除探针为空、QLoRA 冻结集优于基线、三存储正式评测和安全 benign 评测完成前，不使用“机器遗忘”“参数级遗忘”“司法级不可篡改”“100% 私有化”“准确率 95%+”等表述。现场页面必须显示 `live` 或 `offline_fixture`，并诚实展示模型不可用、来源失败和人工复核状态。
