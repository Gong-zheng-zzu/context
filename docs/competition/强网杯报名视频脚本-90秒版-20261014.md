官方限制：MP4，时长不超过 90 秒，文件不超过 20 MB，H.264/AAC，分辨率不低于 800x600。

| 1:12-1:24 | 删除验证证明 | 展示删除前后计数、删除后探针、控制作用域保留、幂等结果和证明哈希。 |

## 录制规则

1. 只录制本次 live 或明确标注的 `offline_fixture` 响应，不用静态成功截图替代服务响应。
2. 服务、模型或存储失败时保留错误和降级状态，不能切换为写死成功画面。
3. 画面不出现 `.env`、JWT、密码、PAT、数据库凭据、真实护理原文或本机路径。
4. 录制前执行 Docker health check、fixture smoke、live smoke 和 `release_guard.py`。
5. 成片后执行：

```powershell
python experiments/scripts/validate_submission_package.py D:\context\submission\2026-强网杯
```
