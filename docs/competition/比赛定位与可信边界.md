# 忆安智护：比赛定位与可信边界

## 推荐定位

**忆安智护：面向智慧养老的护理数据智能治理与可信辅助决策平台**

副标题：**基于多源记忆融合、隐私防护与可追溯生成的智慧养老安全底座**

项目面向养老机构数字化升级中的护理数据治理问题：记录碎片化、检索不可解释、角色权限复杂、敏感信息难以追责，以及用户数据删除难以证明。系统帮助机构把护理数据**记清楚、查得到、防得住、说得明、删得净**。

AI 在本项目中只承担辅助整理、辅助检索、摘要和风险提示职责，不替代护工、医生或机构管理者，也不要求假设养老机构已经普遍部署成熟的 AI Agent。

## 三项可展示创新

1. **护理数据结构化治理**：将护理文本整理为带时间、主体和因果关系的 O-M-P-R 证据，并保留规则、PMI、LLM 等来源。
2. **多源检索与证据审计**：融合向量、知识图谱和时间线来源；结果携带 `doc_id`、来源排名、RRF 分数、延迟和降级状态。
3. **隐私生命周期控制**：按用户和会话隔离数据，提供敏感信息防护、受控审计和可验证的用户级删除。

## 现场演示边界

- **实时模式**：使用受保护 API 和现场可用的 Ollama 模型；展示实际响应，不预填指标。
- **离线夹具模式**：仅展示固定样例和界面流程，不调用模型、检索或安全 API；其输出不属于实验结果。
- **删除验证**：准确称为“隔离用户的 Qdrant/副本向量删除验证”，不宣称已经实现梯度投影式模型遗忘。
- **实验数字**：只引用通过数据集哈希、配置指纹、来源审计和完整样本门禁的结果；未完成的比较不得用目标值或历史示例数字代替。

## 建议答辩话术

> 智慧养老的下一步不是让 AI 替代护理人员，而是先把护理数据治理好。忆安智护提供一层可信底座：记录可结构化、检索有证据、权限可控制、操作能追溯、数据可删除。现场展示的是系统真实执行链路；无法实时执行的部分会明确标记为离线夹具或待评测，不把演示样例包装成模型指标。
