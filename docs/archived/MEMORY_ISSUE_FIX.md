# 🐛 记忆检索问题修复方案

## 问题描述

用户问"我是谁？"时，系统返回了技术栈信息，而不是用户名字。

## 根本原因

### 1. 检索排序问题
当前检索结果（按相似度排序）：
```
1. [相似度:1.0000] 我是谁？我的信息发一下  ← 问题本身（最高分）
2. [相似度:0.7811] 我的API为多少
3. [相似度:0.7503] 我的姓名是什么，我的身份证号为  ← 问题，不是答案
4. [相似度:0.7477] 我刚才跟你讨论的项目是什么
5. [相似度:0.7421] 我正在开发一个电商系统...  ← 技术栈（被LLM选中）
```

**实际存储的内容**（在Qdrant中）：
```json
{"content": "我的姓名是宫正行，身份证号为610125200603221316"}
{"content": "我的名字是宫正行，电话是18291810799，身份证号是610125200603221316"}
```

### 2. 为什么没检索到正确答案？

**语义相似度问题**：
- "我是谁？" 的向量 vs "我的姓名是宫正行" 的向量
- 相似度可能低于 0.7421（技术栈信息的相似度）
- 导致包含答案的记忆被排在后面

## 🔧 修复方案

### 方案1: 优化检索策略（推荐）

**修改文件**: `internal/services/context_service.go`

**当前逻辑**：
```go
// 纯向量相似度检索
results := vectorStore.Search(query, topK)
```

**优化后**：
```go
// 混合检索策略
// 1. 向量检索（语义相似）
vectorResults := vectorStore.Search(query, topK*2)

// 2. 关键词过滤（精确匹配）
if containsPersonalQuery(query) {  // "我是谁"、"我的名字"等
    // 过滤出包含实体信息的记忆
    filteredResults := filterByEntityContent(vectorResults)
    return filteredResults
}

// 3. 重排序（结合多个因素）
rerankedResults := rerank(vectorResults, query, {
    semanticWeight: 0.6,
    keywordWeight: 0.3,
    recencyWeight: 0.1
})
```

### 方案2: 改进存储格式

**当前存储**：
```
用户输入: "我的名字是宫正行"
存储内容: "我的名字是宫正行"  ← 只存储输入
```

**改进后**：
```
用户输入: "我的名字是宫正行"
存储内容: {
  "type": "user_info",
  "category": "personal",
  "entities": ["宫正行"],
  "content": "用户名字是宫正行",
  "metadata": {
    "info_type": "name"
  }
}
```

### 方案3: 添加实体识别层

**流程**：
```
用户输入 → 实体识别 → 标记类型 → 存储时添加标签
                                    ↓
检索时 → 意图识别 → 如果是"我是谁" → 优先检索 type=user_info
```

## 🚀 快速修复（临时方案）

### 修改前端LLM Prompt

**文件**: `chat-demo-fixed.html`（已移除）(行1143)

**当前prompt**：
```javascript
const prompt = `你是一个智能助手，基于用户的历史记忆来回答问题。

用户问题：${redactedUserMessage}

检索到的上下文信息：
${contextInfo.longTermMemory}
...
```

**优化后**：
```javascript
const prompt = `你是一个智能助手，基于用户的历史记忆来回答问题。

用户问题：${redactedUserMessage}

检索到的上下文信息：
${contextInfo.longTermMemory}

⚠️ 重要指令：
1. 如果用户问"我是谁"、"我的名字"、"我的信息"等个人信息问题：
   - 仔细查找上下文中包含"姓名"、"名字"、"我的"等关键词的内容
   - 优先提取包含具体人名、电话、身份证等实体信息的记忆
   - 不要回答技术栈、项目等无关信息

2. 如果上下文中有多条记忆，优先选择：
   - 包含明确答案的记忆（而不是问题本身）
   - 包含实体信息的记忆（人名、地址、电话等）
   - 最近的记忆

3. 回答格式：
   - 直接回答用户的问题
   - 如果找到多条相关信息，全部列出
   - 如果确实没找到，明确告知"未找到相关信息"
...
```
