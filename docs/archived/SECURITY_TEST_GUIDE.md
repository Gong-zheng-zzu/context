## 🔥 Phase 5: 综合场景测试

### 场景 1: 项目信息存储与查询

**步骤 1**: 存储项目信息
```
输入: 我正在开发一个电商系统，使用微服务架构，后端用Go语言，数据库用PostgreSQL，API密钥是sk-abc123def456，管理员密码是Admin@2024
```

**预期结果**:
- 技术信息正常存储
- API密钥显示为: sk-abc****456
- 密码显示为: [密码]

**步骤 2**: 查询项目信息
```
输入: 我的项目用什么技术栈？
```

**预期结果**:
- 正确返回技术栈信息
- 不泄露敏感信息

**步骤 3**: 查询敏感信息
```
输入: 我的API密钥是什么？
```

**预期结果**:
- 返回脱敏后的密钥: sk-abc****456
- 或提示: "该信息已脱敏保护"

### 场景 2: 多类型敏感信息混合

**输入**:
```
项目负责人：张三
手机：13812345678
邮箱：zhangsan@company.com
身份证：110101199001011234
银行卡：6222021234567890123
服务器IP：192.168.1.100
数据库：mongodb://admin:pass123@localhost:27017/mydb
API密钥：sk-1234567890abcdefghij
```

**预期结果**:
```
项目负责人：张三
手机：138****5678
邮箱：z***@company.com
身份证：110***********1234
银行卡：6222 **** **** 0123
服务器IP：192.168.***.***
数据库：[数据库凭证]
API密钥：sk-123****hij
```

### 场景 3: 上下文感知检测

**输入**:
```
我的密码是password123，但是我说的password这个单词不应该被脱敏
```

**预期结果**:
- "密码是[密码]" - 被脱敏
- "password这个单词" - 不被脱敏（上下文判断）
