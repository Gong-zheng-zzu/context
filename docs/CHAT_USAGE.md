# 养老院系统对话功能使用说明

## 功能概述

养老院系统现已支持4个角色的对话功能，每个角色都有专门定制的对话界面和AI助手。

## 各端功能

### 1. 护工端 (caregiver_chat.html)
**功能**：通过对话记录老人的生命体征和护理情况

**使用示例**：
- "记录张奶奶血压130/80，体温36.5度"
- "记录李爷爷今天的护理情况"
- "王奶奶今天服用了降压药"
- "赵爷爷今天有点发烧，需要注意"

**特点**：
- AI自动识别并提取数据
- 简洁专业的护理术语
- 异常数据自动提醒

### 2. 医生端 (doctor_chat.html)
**功能**：通过对话查询和分析健康数据

**使用示例**：
- "显示张奶奶最近3天的血压趋势"
- "分析李爷爷的健康状况"
- "王奶奶有哪些异常指标"
- "生成赵爷爷的健康报告"

**特点**：
- 专业的医学分析
- 数据趋势查询
- 健康报告生成

### 3. 家属端 (family_chat.html)
**功能**：通过对话了解老人健康状况

**使用示例**：
- "我爸爸今天怎么样？"
- "我妈妈最近血压正常吗？"
- "老人今天吃饭怎么样？"
- "有什么需要注意的吗？"

**特点**：
- 温暖关怀的语气
- 通俗易懂的解释
- 让家属放心

### 4. 老人端 (elder_voice_chat.html)
**功能**：对话 + 语音交互

**使用示例**：
- "我今天感觉怎么样"
- "我的血压正常吗"
- "今天吃什么药"
- "我需要注意什么"

**特点**：
- **语音输入**：点击麦克风按钮说话，自动转文字
- **语音播报**：AI回复自动朗读出来
- 大字体显示（20px+）
- 简单易用的界面

## 语音功能说明

### 语音识别
- 使用浏览器原生 Web Speech API
- 支持中文识别
- 点击麦克风按钮开始录音
- 自动识别并填入输入框

### 语音播报
- 自动朗读AI回复
- 语速适中（0.9倍速）
- 适合老人听力

### 浏览器要求
- 需要 HTTPS 或 localhost
- 推荐使用 Chrome/Edge 浏览器
- 需要授权麦克风权限

## 技术实现

### 前端架构
- 4个独立的HTML页面，每个角色一个
- 共用 `chat-common.js` 处理通用逻辑
- 每个页面通过 `ROLE_CONFIG` 配置角色特定行为

### 后端支持
- 根据 `user_id` 前缀自动识别角色
  - `caregiver_*` → 护工端
  - `doctor_*` → 医生端
  - `family_*` → 家属端
  - `elder_*` → 老人端
- 动态调整系统提示词
- 保持现有的JWT认证和记忆系统

### 数据隔离
- 每个用户的会话独立存储
- 使用 `localStorage` 按用户ID隔离
- 支持多用户同时使用

## 启动步骤

1. **启动后端服务**
   ```bash
   cd d:\context\context-keeper-main
   .\server.exe
   ```

2. **访问角色选择页面**
   ```
   http://localhost:8088/web/role_selection.html
   ```

3. **选择角色进入对应端**
   - 点击对应的角色卡片
   - 选择测试用户登录
   - 开始对话

## 注意事项

1. **语音功能**：
   - 仅在老人端启用
   - 需要浏览器支持 Web Speech API
   - 首次使用需授权麦克风权限

2. **数据记录**：
   - 所有对话自动保存到记忆系统
   - 支持文件上传（图片、PDF、文本）
   - 敏感信息自动脱敏

3. **会话管理**：
   - 支持多会话切换
   - 历史记录自动保存
   - 切换用户时数据隔离
