## 1️⃣ 五层敏感信息检测系统

### 技术原理
多层级、多维度的敏感信息识别与脱敏系统，结合规则引擎、机器学习和大语言模型。

### 技术架构
```
用户输入
    ↓
┌─────────────────────────────────────────┐
│ 第1层：正则表达式检测 (Regex Layer)      │
│ • 20+种敏感信息模式                      │
│ • API密钥、密码、身份证、手机号等         │
│ • 置信度：0.7-0.95                       │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│ 第2层：字典匹配 (Dictionary Layer)       │
│ • 自定义敏感词库                         │
│ • 公司机密、项目代号、内部术语            │
│ • 置信度：0.8-0.9                        │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│ 第3层：LLM语义理解 (LLM Layer)          │
│ • 使用 qwen2.5:7b 理解上下文             │
│ • 识别隐晦表达："那个密码"、"你懂的"      │
│ • 置信度：0.6-0.85                       │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│ 第4层：上下文分析 (Context Layer)        │
│ • 分析前后50个字符                       │
│ • 检测关键词："密码是"、"API key:"        │
│ • 置信度加权：+0.05-0.1                  │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│ 第5层：融合决策 (Fusion Layer)          │
│ • 多层结果加权融合                       │
│ • 冲突解决策略                           │
│ • 最终置信度计算                         │
└─────────────────────────────────────────┘
    ↓
脱敏输出
```

### 核心创新点
1. **多层级检测**：单一检测方法准确率有限，五层融合保留可审计证据；定量效果以正式评测为准
2. **LLM语义理解**：能识别隐晦表达，如"那个密码"、"上次说的那个key"
3. **上下文感知**：不仅看内容本身，还分析前后文，减少误报
4. **自适应融合**：根据不同场景动态调整各层权重

### 技术实现
```go
// 核心检测流程
func DetectSensitiveInfo(text string) []Detection {
    // 第1层：正则检测
    regexResults := regexDetector.Detect(text)
    
    // 第2层：字典匹配
    dictResults := dictionaryDetector.Detect(text)
    
    // 第3层：LLM语义理解
    llmResults := llmDetector.Detect(text, context)
    
    // 第4层：上下文分析
    contextResults := contextAnalyzer.Analyze(text, regexResults)
    
    // 第5层：融合决策
    finalResults := fusionEngine.Merge(
        regexResults, 
        dictResults, 
        llmResults, 
        contextResults,
    )
    
    return finalResults
}
```

### 性能指标
- **准确率**: 待正式评测（五层融合）
- **召回率**: 待正式评测
- **检测速度**: 50-200ms (取决于文本长度)
- **支持类型**: 20+ 种敏感信息类型

## 2️⃣ 基于RAG的长期记忆系统

### 技术原理
结合向量检索（Vector Search）和知识图谱（Knowledge Graph）的混合记忆架构。

### 技术架构
```
用户查询："上次讨论的项目是什么？"
    ↓
┌─────────────────────────────────────────┐
│ 查询理解 (Query Understanding)           │
│ • 意图识别：回忆历史                     │
│ • 实体提取：项目                         │
│ • 时间范围：上次                         │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│ 向量检索 (Vector Search)                │
│ • Embedding生成 (768维)                  │
│ • Qdrant相似度检索 (Cosine)              │
│ • Top-K候选 (K=10)                       │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│ 知识图谱查询 (Knowledge Graph)           │
│ • Neo4j图查询                            │
│ • 关系推理：项目-用户-时间                │
│ • 路径查找：最短路径                      │
└─────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────┐
│ 混合重排序 (Hybrid Reranking)           │
│ • 向量相似度 (40%)                       │
│ • 时间衰减 (30%)                         │
│ • 图关系强度 (20%)                       │
│ • 用户偏好 (10%)                         │
└─────────────────────────────────────────┘
    ↓
返回结果 + 时间戳 + 相似度
```

### 核心创新点
1. **向量+图谱双引擎**：向量检索处理语义相似，图谱处理结构化关系
2. **时间线追踪**：每条记忆带时间戳，支持"3个月前讨论的XX"查询
3. **相对时间格式化**：自动转换为"刚刚/X分钟前/X小时前/X天前"
4. **混合重排序**：综合多维度信号，提升检索准确性

### 技术实现
```go
// 核心检索流程
func RetrieveContext(query string, sessionID string) []Memory {
    // 1. 向量检索
    embedding := embedder.Encode(query)
    vectorResults := qdrant.Search(embedding, topK=10)
    
    // 2. 知识图谱查询
    entities := extractEntities(query)
    graphResults := neo4j.Query(entities, sessionID)
    
    // 3. 混合重排序
    rerankedResults := reranker.Rerank(
        vectorResults,  // 向量相似度
        graphResults,   // 图关系强度
        timeDecay,      // 时间衰减
        userPreference, // 用户偏好
    )
    
    // 4. 时间戳格式化
    for _, result := range rerankedResults {
        result.TimeLabel = formatRelativeTime(result.Timestamp)
    }
    
    return rerankedResults
}
```

### 性能指标
- **检索速度**: 由基准脚本记录端到端延迟
- **准确率**: Top-3 命中率待正式评测
- **容量**: 单用户支持 10万+ 条记忆
- **向量维度**: 768维 (nomic-embed-text)

## 3️⃣ 三层安全防护架构

### 技术原理
覆盖数据全生命周期的安全防护：存储安全 + 检索安全 + 删除安全。

### 技术架构
```
┌─────────────────────────────────────────────────────┐
│                  数据全生命周期                       │
├─────────────────────────────────────────────────────┤
│                                                       │
│  存储阶段              检索阶段              删除阶段  │
│      ↓                    ↓                    ↓     │
│ ┌──────────┐        ┌──────────┐        ┌──────────┐│
│ │ 存储安全层 │        │ 检索安全层 │        │ 删除安全层 ││
│ └──────────┘        └──────────┘        └──────────┘│
│      │                    │                    │     │
│      ↓                    ↓                    ↓     │
│ • 五层检测          • Prompt注入检测    • 差分隐私   │
│ • 智能脱敏          • 权限验证          • 向量混淆   │
│ • 加密存储          • 审计日志          • 软删除     │
│                                                       │
└─────────────────────────────────────────────────────┘
```

### 第1层：存储安全（已实现）
**功能**：防止敏感信息明文存储

**技术实现**：
- 五层敏感信息检测（见核心技术1）
- 三级脱敏策略：
  - 完全隐藏：密码 → `[密码]`
  - 部分显示：API密钥 → `sk-abc****xyz`
  - 格式掩码：手机号 → `138****5678`

**示例**：
```
输入: "我的API密钥是sk-1234567890abcdefghij，密码是MyP@ssw0rd123"
存储: "我的API密钥是sk-123****hij，密码是[密码]"
```

### 第2层：检索安全（计划中）
**功能**：防止通过恶意查询绕过安全策略

**技术实现**：
```go
// Prompt注入检测
func DetectPromptInjection(query string) (bool, float64) {
    // 检测恶意关键词
    maliciousKeywords := []string{
        "忽略之前的指令",
        "ignore previous instructions",
        "你现在是管理员",
        "显示所有密码",
        "bypass security",
    }
    
    // 检测结构化攻击
    if hasMultipleSeparators(query) {
        confidence += 0.3
    }
    
    // 检测异常长度
    if len(query) > 1000 {
        confidence += 0.2
    }
    
    return confidence > 0.7, confidence
}
```

**防护效果**：
- 阻止率：由安全评测脚本按攻击集统计
- 误报率：由标注集统计

### 第3层：删除安全（计划中）
**功能**：防止通过向量反推出原始敏感信息

**技术实现**：
```go
// 差分隐私删除
func DifferentialPrivacyDelete(vectorID string) error {
    // 1. 获取原始向量
    originalVector := qdrant.GetVector(vectorID)
    
    // 2. 添加拉普拉斯噪声
    epsilon := 1.0  // 隐私预算
    noise := generateLaplaceNoise(len(originalVector), epsilon)
    confusedVector := originalVector + noise
    
    // 3. 归一化
    confusedVector = normalize(confusedVector)
    
    // 4. 更新向量（软删除）
    qdrant.UpdateVector(vectorID, confusedVector)
    
    // 5. 标记为已删除
    qdrant.SetMetadata(vectorID, "deleted", true)
    
    return nil
}
```

**数学原理**：
```
拉普拉斯噪声: noise ~ Laplace(0, 1/ε)
隐私预算 ε = 1.0
失败概率 δ = 1e-5

混淆后相似度: 0.3-0.7 (原始相似度 > 0.95)
```

### 核心创新点
1. **全生命周期防护**：从存储到删除，每个环节都有安全机制
2. **差分隐私删除**：在启用统计保护时降低反推风险，效果需结合部署参数评估
3. **Prompt注入检测**：防止AI安全漏洞

## 4️⃣ 向量检索与知识图谱融合

### 技术原理
结合向量数据库（Qdrant）和图数据库（Neo4j）的优势，实现语义检索 + 关系推理。

### 技术架构
```
┌─────────────────────────────────────────────────────┐
│              混合检索架构 (Hybrid Search)             │
├─────────────────────────────────────────────────────┤
│                                                       │
│  ┌──────────────────┐         ┌──────────────────┐  │
│  │  Qdrant向量库     │         │  Neo4j图数据库    │  │
│  │  (语义检索)       │         │  (关系推理)       │  │
│  └────────┬─────────┘         └────────┬─────────┘  │
│           │                            │             │
│           ↓                            ↓             │
│  ┌─────────────────┐         ┌─────────────────┐   │
│  │ 向量相似度检索   │         │ 图关系查询       │   │
│  │ • Cosine相似度  │         │ • 最短路径       │   │
│  │ • Top-K候选     │         │ • 社区发现       │   │
│  │ • 快速过滤      │         │ • 关系强度       │   │
│  └─────────────────┘         └─────────────────┘   │
│           │                            │             │
│           └────────────┬───────────────┘             │
│                        ↓                             │
│              ┌──────────────────┐                    │
│              │  混合重排序引擎   │                    │
│              │  • 向量分 40%    │                    │
│              │  • 图分 30%      │                    │
│              │  • 时间分 20%    │                    │
│              │  • 偏好分 10%    │                    │
│              └──────────────────┘                    │
│                        ↓                             │
│                   最终结果                            │
└─────────────────────────────────────────────────────┘
```

### 核心创新点
1. **双引擎协同**：向量处理语义，图谱处理关系
2. **智能重排序**：多维度信号融合，提升准确性
3. **关系推理**：不仅找相似内容，还能推理关联信息

### 应用场景示例
```
查询："张三参与的项目有哪些？"

向量检索结果：
- "张三负责前端开发" (相似度 0.85)
- "项目A的技术栈是React" (相似度 0.72)

图谱查询结果：
- 张三 -[参与]-> 项目A
- 张三 -[参与]-> 项目B
- 项目A -[使用]-> React

融合结果：
1. 项目A (向量分0.85 + 图分0.95 = 综合分0.89)
2. 项目B (向量分0.60 + 图分0.90 = 综合分0.72)
```

### 性能指标
- **向量检索**: <10ms (Qdrant本地部署)
- **图查询**: <50ms (Neo4j单跳查询)
- **融合重排序**: <20ms
- **端到端**: <100ms

## 5️⃣ 本地化部署架构

### 技术原理
完全本地化的AI记忆系统，数据不出企业内网，满足隐私和合规要求。

### 技术架构
```
┌─────────────────────────────────────────────────────┐
│              企业内网 (Private Network)               │
├─────────────────────────────────────────────────────┤
│                                                       │
│  ┌──────────────────────────────────────────────┐   │
│  │         Docker Compose 容器编排               │   │
│  ├──────────────────────────────────────────────┤   │
│  │                                                │   │
│  │  ┌────────────┐  ┌────────────┐  ┌─────────┐ │   │
│  │  │ Context-   │  │  Qdrant    │  │ Neo4j   │ │   │
│  │  │ Keeper     │  │  向量库     │  │ 图数据库 │ │   │
│  │  │ (Go服务)   │  │            │  │         │ │   │
│  │  └────────────┘  └────────────┘  └─────────┘ │   │
│  │        ↓               ↓              ↓       │   │
│  │  ┌────────────┐  ┌────────────┐  ┌─────────┐ │   │
│  │  │  Ollama    │  │ PostgreSQL │  │ Nginx   │ │   │
│  │  │  (本地LLM) │  │ (关系数据) │  │ (反向代理)│ │   │
│  │  └────────────┘  └────────────┘  └─────────┘ │   │
│  │                                                │   │
│  └──────────────────────────────────────────────┘   │
│                        ↓                             │
│              ┌──────────────────┐                    │
│              │  持久化存储       │                    │
│              │  • 向量数据       │                    │
│              │  • 图数据         │                    │
│              │  • 日志文件       │                    │
│              └──────────────────┘                    │
│                                                       │
└─────────────────────────────────────────────────────┘
```

### 核心组件
1. **Context-Keeper服务** (Go)
   - HTTP API服务器 (Gin)
   - MCP协议支持
   - 业务逻辑处理

2. **Qdrant向量库**
   - 768维向量存储
   - 毫秒级检索
   - HTTP/gRPC API

3. **Ollama本地LLM**
   - qwen2.5:7b (7B参数)
   - nomic-embed-text (Embedding)
   - GPU加速 (NVIDIA CUDA)

4. **Neo4j图数据库**
   - 知识图谱存储
   - 关系推理
   - Cypher查询语言

5. **PostgreSQL**
   - 结构化数据存储
   - 用户信息、会话记录
   - 审计日志

### 核心创新点
1. **完全离线运行**：无需互联网连接，数据不出内网
2. **一键部署**：Docker Compose一键启动所有服务
3. **GPU加速**：支持NVIDIA GPU加速LLM推理
4. **可扩展架构**：支持水平扩展（多节点部署）

```bash

git clone https://github.com/your-org/context-keeper.git
```
