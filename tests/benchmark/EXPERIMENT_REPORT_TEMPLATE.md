## 五、PCCM算法评估

### 5.1 PCCM置信度融合公式

```
C_final = (w1·C_regex + w2·C_dict + w3·C_llm) × (1 + 0.1·(n-1))
```

当前权重配置：
- w1 (正则表达式) = 0.85
- w2 (PMI词典) = 0.10
- w3 (LLM) = 0.05
